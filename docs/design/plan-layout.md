# 품질관리계획서 전체 — 쪽 유형별 양식 명세 (정본 대조)

현장에서 승인받은 품질관리계획서 전문(개정본 PDF, A4 세로)을 쪽 유형별로 재어(300dpi 래스터의 선·잉크, `pdftotext -bbox-layout` 글자 상자) 얻은 **모양 수치**다.
구현은 `src/danburn/plan_doc.py`(표지·목차·이력·장 쪽·절 개요 칸)와 `src/danburn/hwpx_out.py`(쪽 설정·쪽 머리·8.11 표) 상수와 1:1로 맞춘다.
로고·CI·회사명·현장명·사람 이름·원문 문장·실제 수량은 싣지 않는다. 8.11 표 자체는 [`8.11-layout.md`](8.11-layout.md)가 기준이고, 이 문서 §8이 그 뒤 바뀐 값을 적는다.

- 길이는 mm(쪽 왼쪽 위 기준), 글자 크기는 pt, 줄 간격은 %(한컴 "글자에 따라" 비율).
- 글자 크기 = 한글 잉크 높이 ÷ 0.88 (8.11 명세 §9와 같은 환산). 선 굵기 등급: < 0.25 가는선, ≤ 0.45 중간선.
- "측정" = 정본, "채택" = 우리 값. 대조 도구: `scripts/dev/design_diff.py`(L6-T1). 허용: 위치 ≤ 1.0mm, 글자 ≤ 0.5pt, 열 비율 ≤ 2%p, 선 같은 등급.

## 3. 표지

쪽 전체를 선 없는 3칸 표 하나로 두고 **행 높이로 자리를 고정**한다(빈 문단 쌓기는 뷰어마다 어긋난다). 쪽 머리 없음.

| 문서명 "품질관리계획서" | 약 45.5pt, 보통 굵기, 글 상자 위 88.5 | 45.5pt, 행 86.0~108.0 |

| 정보 글 | 12pt, 항목 이름 굵게, 왼쪽 안여백 4.4, "항목 :  값" | 같음 |

측정 도구의 표지 `table.*`·여백 항목은 표지 모양 판정에 쓰지 않는다. 도구는 쪽 안 세로선을 모두 모아 표로 보는데, 정본 표지 세로선 중 로고 영역을 뺀 9개 가운데
7개(x 95.9·111.6·120.9·124.4·127.3·142.2·157.4, y 90~103)는 문서명 44pt 글자 상자(y 88.5~105.4) 안의 **글자 획**이고, 표 선은 x 67.6·146.4(y 149~192) 두 개뿐이다
→ "x 61.4~162.4, 6열 31.4/17.6/…" 은 글자 획 + 상자 선이 섞인 값. 좌우 여백 22.9/19.0 은 정본 공사명 글이 차지한 폭(22.2~191.9)이라 공사명 길이에 따라 달라진다.
정보 상자는 래스터 선으로 대조한다: 정본 67.5~146.6 × 149.0~191.9, 우리 68.0~147.1 × 149.0~191.8(차 ≤ 0.5).

개요 칸 뒤 본문(`body`: 방침 글·{표:…})은 장 쪽 모양(§6)으로 `1. {body_label}` 제목 아래 이어 쓴다. {표:…} 자료 표는 9pt, 머리행 8.0 굵게(쪽마다 반복), 줄 최소 7.0, 바깥 0.4 · 안 0.12.
8.11 절은 개요 칸 뒤 **새 쪽**에서 `1. 품질시험 및 검사계획`과 8.11 표를 시작한다(정본은 흐름표 뒤 새 쪽).
