# 8.11 검사 및 시험, 모니터링 — 표 양식 명세

현장에서 승인받은 품질관리계획서의 8.11 품질시험계획표 한 쪽을 PDF로 재어(300dpi 래스터·글자 상자) 얻은 **모양 수치**다.
구현은 `src/danburn/hwpx_out.py` 상수와 1:1로 맞춘다. 로고·CI·회사명·현장명·실제 수량·원문 문장은 싣지 않는다.
길이는 mm, 글자 크기는 pt. "측정"은 원본에서 잰 값, "채택"은 우리 값이다(다르면 이유를 적는다).

## 1. 용지·여백

| 항목 | 측정 | 채택 |
|---|---|---|
| 용지 | A4 세로 | A4 세로 (`landscape=True` 선택 시 A4 가로, 열 너비는 본문폭에 비례해 늘린다) |
| 표 왼쪽·오른쪽 끝 | 16.5 / 197.2 | 왼쪽 여백 16, 오른쪽 여백 13 → 본문폭 181 |
| 쪽 머리 시작(문서명 윗선) | 약 17 | 위 여백 16.5 |
| 본문 시작 | 약 36 | 위 여백 + 머리말 16.5 = 33 |
| 아래 | 표 끝 약 272 | 아래 여백 10 + 꼬리말 8 |

방향 표기(HWPX `hp:pagePr`): 폭·높이는 늘 세로 용지 치수(59528×84189 HWPUNIT)로 두고, 방향은 `landscape` 속성으로만 준다 — 세로 `WIDELY`, 가로 `NARROWLY`(OWPML 값은 이 둘뿐이다).

## 2. 쪽 머리(머리말 영역)

선 없는 3칸 2줄 표, 폭 = 본문폭.

| 칸 | 폭 | 1줄 (7.0) | 2줄 (8.0) |
|---|---|---|---|
| 로고 칸 | 17.7 | 두 줄 병합, 선 없음 — 로고 그림 + 그 아래 회사명 | (병합) |
| 가운데 | 본문폭 − 17.7 − 64 | 문서명 "품질관리계획서" 15pt 굵게 (오른쪽 칸까지 병합) | 절 제목 "8.11 검사 및 시험, 모니터링" 13pt |
| 오른쪽 | 64 | (병합) | `YYYY.MM.DD. [Rev.N] Np.` 9pt, 오른쪽 정렬 |

- 가운데·오른쪽 칸의 두 줄 아래에 0.4mm 선. 측정: y = 23.4 / 31.5, 선은 x = 33.7(로고 칸 오른쪽)에서 시작.
- 글은 칸 아래쪽에 붙인다. 쪽 번호는 머리말 안의 자동 번호(`autoNum numType="PAGE"`) + "p." 한 곳에만 둔다. 개정일이 없으면 `[Rev.N] Np.`만 쓴다.

### 로고 칸 (사용자 로컬 입력)

- 측정: 원본 로고 그림 한 장이 약 13.2 × 12.1(그림 안에 회사 표기 포함), 가로 약 18.7~31.9, 세로 약 17.2~29.3. 선보다 왼쪽이며 두 줄 높이에 걸친다.
- 입력: `logo`(PNG/JPEG 파일 경로), `company`(회사명 글). **저장소에는 어떤 로고·회사명도 넣지 않는다** — 사용자가 로컬에서 넘긴 값만 쓴다.
- 칸 안은 1열 표(선·여백 없음)로 나눈다: 그림 줄 + 회사명 줄(3.5, 8pt 굵게, 가운데). 한 셀에 그림 문단과 글 문단을 쌓으면 뷰어가 겹쳐 그려서 줄을 나눴다.
- 그림 상자: 폭 min(13.2, 칸 안쪽 폭 16.7) × 높이 12.1(회사명이 있으면 12.1 − 3.5 = 8.6). 비율을 지켜 상자 안에 맞춘다. 그림은 글자처럼 취급, 위아래 배치.
- 둘 다 없으면 칸은 **빈 채 폭을 유지**한다 → 쪽 머리 선 위치는 로고 유무와 상관없이 같다.

## 3. 본문 머리

- 절 번호 줄 "1. 품질시험 및 검사계획" 10pt, 왼쪽. (원본은 뒤에 블록 표기가 붙는다 — 우리는 넣지 않는다.)
- 분야 머리 `[건축공사]`·`[토목공사]` 10pt, 표 바로 위. 둘째 분야부터 새 쪽에서 시작한다.
- 표 아래(마지막 표 뒤)에 근거 기준·자동 산출 주석 8pt.

## 5. 머리행

2줄, 각 6.3 (측정 합 12.6), 글자 8pt 가운데.

```
┌──┬────┬──────┬───┬──┬─────────────┬──────────┬──┐
│  │    │      │   │  │   시험빈도   │ 계획횟수  │  │
│공종│시험항목│ 시험종류 │수량│단위├──────┬──────┼───┬───┬──┤비고│
│  │    │      │   │  │      │ 산출근거 │현장│외부│KS│  │
└──┴────┴──────┴───┴──┴──────┴──────┴───┴───┴──┴──┘
```

- 공종·시험항목·시험종류·수량·단위·비고는 두 줄 세로 병합. 시험빈도는 두 칸 가로 병합(아래 줄 왼칸은 비움, 오른칸 "산출근거"). 계획횟수는 세 칸 가로 병합(아래 줄 현장·외부·KS).
- 쪽이 넘어가면 머리행 2줄을 반복한다(`repeatHeader`), 표는 셀 단위로 나뉜다.

## 6. 본문 행

- 최소 높이 4.8 (측정: 한 줄 행 4.8). 글이 길면 늘어난다 — 선언 높이를 글 길이로 추정해 넣는다(한글 1em, 영숫자 0.55em, 여유 35%, 줄 높이 1.3em). 뷰어마다 쪽 나눔이 어긋나지 않게 하기 위해서다.
- 셀 안 여백: 좌우 0.5, 위아래 0.3 (측정: 글 시작이 선에서 0.3~0.4).
- 수량: 정수면 천 단위 쉼표, 아니면 소수 둘째 자리. 수량이 없으면 "-".
- 시험항목이 9자보다 길면 규격 괄호 앞에서 줄을 바꾼다: `레미콘` / `(25-24-150)`.
- 계획횟수 KS 칸의 표기(◎ 등)는 행 값 그대로 가운데 정렬.

## 7. 병합 규칙

| 열 | 병합 조건(연속 행) |
|---|---|
| 공종 | 공종이 같다. 공종이 비어 있으면 자재 기본 공종(레미콘·철근 → 철근콘크리트공사)으로 본다 |
| 시험항목·수량 | 같은 공종·같은 시험항목(자재·규격)·같은 값 |
| 시험종류·시험빈도·산출근거 | 같은 공종·같은 자재·같은 시험종류·같은 글 — 철근처럼 규격마다 한 행인 묶음이 여기에 해당 |
| 단위 | 같은 단위이고, 같은 시험항목이거나 위 묶음 |
| 비고 | 비어 있지 않은 같은 글이고, 같은 시험항목이거나 위 묶음 |
| 계획횟수(현장·외부·KS) | 병합하지 않는다 |

공종 칸: 병합이 3행 이상이고 다른 칸이 정한 높이 안에 들어가면 한 글자씩 세로로 쌓는다(글자마다 문단). 아니면 가로로 줄바꿈해 적는다. (`textDirection=VERTICAL`은 뷰어마다 줄바꿈이 달라 쓰지 않는다.)

## 8. 선

| 선 | 측정 | 채택 |
|---|---|---|
| 표 바깥 네 변 | 약 0.35~0.4 | 0.4mm |
| 안쪽(머리행 아래 포함) | 약 0.17~0.25 | 0.2mm |
| 쪽 머리 두 줄 아래 | 약 0.4 | 0.4mm |

모든 선은 검정 실선. 대각선·음영 없음.

## 9. 글꼴

- 원본은 고딕 계열. 채택: **함초롬돋움**(새 문서 기본 글꼴 목록의 0번)만 참조한다. 임베딩하지 않는다(`isEmbedded="0"`). 상용 글꼴 계열은 쓰지 않는다.
- 크기(측정한 한글 글자 높이 ÷ 0.88로 환산): 문서명 15 굵게, 절 제목 13, 개정 표기 9, 절 번호·분야 머리 10, 표 머리 8, 본문 8 / 긴 문장 칸 7, 꼬리말 7.

## 10. 꼬리말

가운데 7pt 한 줄: 한컴 공개 문서 고지 문구(`NOTICE`, 원본 AGENTS §4 의무). 원본 양식에는 없는 줄이다.

## 11. 시험계획 미작성 자재 표 (8.11 뒤)

규칙이 없는 자재가 문서에서 조용히 빠지지 않게, 분야별 표 뒤(근거 주석 앞) 같은 구역에 붙인다. 원본 양식에는 없는 표다. 항목이 없으면 제목도 표도 넣지 않는다.

- 제목 `[시험계획 미작성 자재 (확인 필요)]` 10pt 왼쪽(분야 머리와 같은 모양).
- 머리 1행(6.3, 8pt 가운데, 쪽이 넘어가면 반복) + 항목마다 1행(최소 4.8, 글 길이로 늘어남). 병합 없음.
- 선·글꼴·셀 여백은 8.11 표와 같다(바깥 0.4mm·안 0.2mm, 함초롬돋움, 좌우 0.5·위아래 0.3).
