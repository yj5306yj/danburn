Open source · Claude Code plugin

A Claude Code plugin that drafts Quality Management Plans for Korean construction sites

Danburn drafts the Quality Management Plan that Korean law requires of construction projects above a set size, from the contractor's bill of quantities.

Built and run by Sanghyun Lee, a former site quality manager on public housing projects in Korea.

GitHub repository Install

Apache-2.0 · The plugin's interface and output are in Korean.

Works inside Claude Code

Danburn ships as a Claude Code plugin. Install it once, then ask Claude: /danburn:start to draft a new plan, /danburn:check to audit an existing one, /danburn:test-plan to export the test plan.

Install — two lines in a terminal

claude plugin marketplace add https://github.com/yj5306yj/danburn
claude plugin install danburn@danburn

Requires uv. The same tool also runs from a plain terminal as danburn.

How the work is split

Claude Code

Runs the tool, asks its questions one at a time, passes your answers back, and reports the result along with the list of items to confirm.

Deterministic code

Reads the bill of quantities, matches items to test standards, and calculates the test counts. Each row cites its basis. Items with no rule are flagged, not guessed.

The quality manager

Checks the draft against site conditions and confirms it before submission.

Three skills

Draft a new plan

You give
A bill of quantities (xlsx) and answers to a few questions
You get
A draft Quality Management Plan (.hwpx, the Korean word-processor format) and a list of items for a person to confirm
In Claude Code
/danburn:start

Export the test plan

You give
The output folder from /danburn:start — no further questions
You get
The quality test plan on its own, as HWPX and Excel, from the same calculation as the full plan
In Claude Code
/danburn:test-plan output-folder

Audit an existing plan

You give
One existing plan file (hwp, hwpx or pdf), including plans written by someone else
You get
A list of cited standards that have since been revised or repealed: where in the plan, what to change, and a link to the official source
In Claude Code
/danburn:check plan.hwp

Who makes it

Built and run by a former site quality manager

Danburn is built and run by Sanghyun Lee, a former site quality manager on public housing projects in Korea. Independent and self-funded. Started in September 2026.

Writing a Quality Management Plan meant looking up standards, recounting quantities every time the bill of quantities changed, and reworking a long document, a month or two each time. Danburn is meant to cut that to feeding in the bill of quantities once.

What the output is
