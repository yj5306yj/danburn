무엇을 넣고 무엇이 나오나

  1. 1 · 넣는 것

    도급내역서(xlsx)

    지급·사급 내역 시트가 있는 공동주택 도급내역서. 읽을 수 있는 양식인지 먼저 확인합니다.

  2. 2 · 답하는 것

    질문 몇 개

    발주자(공공·민간), 공사 규모, 현장 이름과 사람. 답으로 적용 법(품질관리계획 대상, 품질관리자·시험실 기준)을 판정합니다.

  3. 3 · 나오는 것

    품질관리계획서.hwpx

    한글에서 열리는 계획서 한 권과, 사람이 확인할 것 목록.

계획서에 들어가는 것

1~10장 틀

「건설공사 품질관리 업무지침」 별표1 순서의 33절. 절마다 개요 칸·업무 분장표·업무 흐름표, 기록 양식 42종. 문장은 모든 현장에 같은 공통 초안이라 현장에 맞게 고쳐 씁니다.

8.11 시험계획 계산

내역서 물량으로 별표2의 시험종목·빈도·계획횟수를 계산하고 행마다 산출근거를 적습니다. 규칙이 없는 자재는 따로 표시합니다.

법 판정

건설기술 진흥법 시행령 제89조와 시행규칙 별표5로 계획 종류와 품질관리자·시험실 기준을 판정해 1장과 8.11에 적습니다.

비고결과는 제출 전 검토용 초안이며, 확정은 품질관리자가 합니다. 법정 서식 충족이나 승인을 보장하지 않습니다. 만들 때는 한글(한컴오피스)이 필요 없고, 제출 전에는 한글로 열어 확인합니다. 맥에서 만들고 확인했으며 Windows는 아직 검증 전입니다.

설치와 실행

터미널에서 한 줄

uvx --from git+https://github.com/yj5306yj/danburn danburn start

uv가 있어야 합니다. 계속 쓸 거라면 pipx install git+https://github.com/yj5306yj/danburn 후 danburn start.

AI 에이전트에게 맡기기

Claude Code·Codex 같은 코딩 에이전트에 저장소의 스킬을 연결하고 “이 폴더의 도급내역서로 품질관리계획서 만들어 줘”라고 말합니다. 에이전트가 같은 질문을 대신 묻습니다.

만든 사람

LH 공공주택 현장 품질관리자 출신 개발자가 만들었습니다

착공 전에 품질관리계획서를 쓰고, 공사 내내 고쳐 냈습니다. 기준을 찾고, 바뀌는 내역서로 수량을 다시 셈하고, 긴 한글 문서를 손보는 데 한 번에 한두 달씩 걸렸습니다.

그 일을 내역서 한 번 넣는 것으로 줄이려고 만든 도구입니다. 가장 공들인 곳은 8.11 검사 및 시험, 모니터링입니다.

개인이 만든 오픈소스 · Apache-2.0 · GitHub

감사와 출처

아래 공개 소프트웨어와 공개 자료 덕분에 만들 수 있었습니다. 전체 목록과 라이선스는 저장소의 NOTICE.md에 있습니다.

한글 문서·파일 처리 오픈소스

  • python-hwpx Apache-2.0 한컴 없이 HWPX를 만들고 검사
  • rhwp MIT 한컴 없이 HWPX를 PDF로 그려 쪽 모양 확인(개발 도구)
  • lxml BSD-3-Clause HWPX 속 XML 처리
  • openpyxl MIT 도급내역서 xlsx 읽기
  • PyYAML MIT 규칙·현장 정보 읽기
  • uv Apache-2.0 OR MIT 설치를 한 줄로

법령·기준 공개 자료

  • legalize-kr/admrule-kr, 행정규칙 공개 미러(업무지침 현행 판 확인)
  • 국가법령정보센터 · 공동활용 API, 업무지침 별표1·별표2와 건설기술 진흥법·시행령·시행규칙 원문
  • 국가건설기준센터(KCSC), KCS·KDS·LHCS 번호·명칭 확인
  • 공공데이터포털, 공개 법령·기준 API 조사
  • 한컴 HWP/OWPML 공개 문서, HWP·HWPX 문서 구조 참고

본 제품은 한글과컴퓨터의 HWP 문서 파일(.hwp) 공개 문서를 참고하여 개발하였습니다.

법령·고시 원문은 옮기지 않고 번호·항목명·쪽만 인용합니다. 글꼴 파일과 한컴오피스 소프트웨어는 포함하지 않습니다.
